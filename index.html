📚 PDF 가로 스크롤 리더

여러 폴더의 PDF + 이미지(JPG/PNG 등)를 추가 순서대로 합쳐서 한 줄로 이어 붙이고,
좌우로 스크롤해서 만화처럼 볼 수 있어요.

📁
폴더를 여기에 드래그&드롭  또는  아래 버튼으로 추가
추천: 폴더 여러 개를 한꺼번에 드래그&드롭 (이름순으로 자동 정렬)
※ PDF 합치기: PDF만 → 1개 PDF (이미지 방식)  /  사진 zip: 사진 원본 그대로 압축  /  사진 → PDF: 사진 각 1페이지씩 PDF 변환
💡 사용법
1. 폴더 여러 개를 한꺼번에 드래그&드롭 (추천)하거나 📁 폴더 추가 버튼 사용 — 폴더는 이름순으로 자동 정렬됩니다 (숫자순: 폴더1 → 폴더2 → 폴더10)
   • 따로 추가한 사진/파일은 각각 한 행씩 올라와서 ↑↓로 자유롭게 순서 조정 가능 (자동 이름 정렬 적용)
   • 각 폴더에 같은 이름 파일(예: 1.pdf, 2.pdf)이 있어도 문제없어요 — 폴더1 전체 → 폴더2 전체 순서가 되고, 페이지 좌측 라벨에 폴더명이 표시됩니다
2. 폴더 안의 PDF·이미지는 숫자 순으로 섞여 정렬돼요: 1 → 2 → … → 10 (1.jpg, 1.pdf 같은 건 번호 → 확장자 순)
   • JPG·PNG·WEBP·GIF·BMP·AVIF·HEIC·TIFF·SVG 등 다양한 이미지 지원 (브라우저에서 못 여는 형식은 그 페이지만 표시 오류 처리, 나머지는 정상 진행)
3. 읽기 화면에서: 마우스 휠·트랙패드로 좌우 스크롤 / ← → 방향키 / 화면 클릭(오른쪽 4/5=다음, 왼쪽 1/5=이전) / + - 키로 확대 축소
4. 내보내기: ⬇ PDF 합치기=PDF만 → 1개 PDF / 📷 사진 zip=사진 원본 그대로 압축 / 📷 사진 → PDF=사진 각 1페이지씩 PDF 변환
