PDF 가로 스크롤 리더 — 사용법
============================

여러 폴더의 PDF + 이미지(JPG/PNG 등)를 순서대로 합쳐서
좌우로 스크롤해서 만화처럼 보는 앱입니다.
모든 처리가 브라우저 안에서만 이루어져 파일이 외부로 전송되지 않습니다.


[사용법]
1. 폴더 여러 개를 한꺼번에 드래그&드롭 (추천) 또는 "📁 폴더 추가" 버튼
   - 폴더는 이름순(폴더1 → 폴더2 → 폴더10)으로 자동 정렬, ↑↓로 미세 조정
   - 각 폴더 안 파일은 숫자순(1 → 2 → 10)으로 정렬
2. "▶ 읽기 시작"
   - 마우스 휠/트랙패드로 좌우 스크롤, ← → 키, 화면 클릭으로 넘기기
   - + - 키 또는 하단 버튼으로 확대/축소
3. (선택) "⬇ 하나로 합친 PDF 받기" — 모든 페이지를 하나의 PDF로 저장
   ※ 페이지를 이미지로 변환하는 방식이라 독서 화면과 동일하게 표시되지만
     텍스트 선택/복사는 불가합니다.


[실행 방법]

A. 가장 간단 (브라우저에서 바로)
   - index.html 을 더블클릭
   - 오프라인에서도 동작합니다 (PWA 기능만 제외)

B. PWA로 설치 (설치한 뒤 서버 없이도, 인터넷 없이도 오프라인 사용)
   ※ 서비스 워커는 http(s) 환경에서만 작동하므로 (file://에서는 불가)
      한 번이라도 http 서버로 열어줘야 합니다.
   1) 이 폴더에서 터미널/명령 프롬프트 실행:
        python3 -m http.server 8000
        (Windows: python -m http.server 8000)
   2) 브라우저로 http://localhost:8000 열기
   3) Chrome/Edge 메뉴(⋮) → "앱 설치" / "PDF 리더 설치"
      (또는 화면에 뜨는 "⬇ 앱으로 설치" 버튼)
   4) 이제 시작 메뉴/데스크톱에서 "PDF 리더"가 아이콘으로 생기고,
      http 서버를 껐어도, 인터넷이 꺼져도 앱이 정상 작동합니다
      (한 번 접속해서 캐시가 만든 이후부터)
   ※ 모바일(Chrome): 주소창의 "앱 설치" 아이콘 또는 공유 메뉴 → "홈 화면에 추가"

   ※ 다른 기기에서 쓰기: 서버를 랜(LAN)에 열면(바인딩 주소 0.0.0.0)
      같은 네트워크 기기에서 http://(서버 PC IP):8000 로 접속 가능


[파일 구성]
  index.html            메인 앱
  sw.js                 서비스 워커 (오프라인 캐시)
  manifest.webmanifest  PWA 매니페스트
  lib/                  pdf.js · pdf-lib 라이브러리 (오프라인 번들)
  icons/                앱 아이콘
